# Bilas Laundry

Website sederhana untuk usaha laundry: daftar harga, kalkulator biaya, dan tombol pesan lewat WhatsApp.

## Fitur

- Kalkulator biaya berdasarkan layanan, berat, dan antar-jemput
- Pesan langsung lewat WhatsApp dengan detail pesanan terisi otomatis
- Daftar harga dan alur kerja
- Tampilan responsif, mendukung mode terang dan gelap

## Teknologi

HTML, CSS, dan JavaScript (tanpa framework).

## Cara menjalankan

1. Unduh atau clone repositori ini.
2. Buka `index.html` di browser.

## Struktur file

- `index.html`: struktur halaman
- `style.css`: tampilan
- `script.js`: kalkulator dan tautan WhatsApp
